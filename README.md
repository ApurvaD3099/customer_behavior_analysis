# customer_behavior_analysis
Customer Behaviour related to subscription, age group, purchases analysis project using python, Postgres SQL, PowerBi
The project covers the complete analytics workflow, including:

Loading and analyzing datasets using Python

Performing Exploratory Data Analysis (EDA)
Cleaning and preparing raw data
Storing and managing data using PostgreSQL
Connecting the processed data to a database server
Building an interactive Power BI dashboard
Creating analytical reports
Preparing a professional PowerPoint presentation using Gamma AI
Evaluating how data visualization and business intelligence can help a clothing store improve its performance.
Which product categories are most profitable?
Which products have low sales?
Exploratory Data Analysis is performed to identify patterns, relationships, trends, and potential problems within the dataset.

The EDA process includes:

Data Understanding
Dataset dimensions

Data types

Unique values

Descriptive statistics

Sales Analysis
Total sales

Average sales

Sales by product

Sales by category
Customer Analysis
Customer purchasing behavior
